功能说明

只对地图行走触发的普通随机暗雷生效。达到等级门槛后，Mod 跳过战斗转场，结算敌群基础奖励。Boss、剧情战、固定事件战都保留正常战斗；无法确认的遭遇也不会自动结算。

EXP经验与职业点数

结算 EXP、JP 和金钱，包含已验证的原生被动、装备、村庄加成与训练奖励。

DROP概率掉落

按原生背包容量加入掉落物；满堆叠时只截断道具数量。

F6快捷开关

按 F6 切换并保存启用状态，提示语言跟随游戏界面语言。

保留原生稀有／首次敌群抽选。限回合料理生效、任务专用掉落和无法确认的遭遇保留正常战斗。

结算条件

仅当最高上场等级达到敌群与地区等级门槛时，才会跳过普通暗雷战斗：

最高上场等级 ≥ max（地区危险等级，抽中敌群最高等级）+ LevelMargin

默认 LevelMargin=1。即使等级符合，非普通随机遭遇仍进入原生战斗。

  • 存活出战角色与原生训练名单获得对应奖励；倒下的出战角色不获得 EXP 或 JP。
  • 出战与训练角色真正升级后，该角色恢复 HP/SP。
  • 通过已验证的原生奖励接口与训练名单结算；具体覆盖范围见实机验证记录。

安装

适配 Windows Steam AppID 3014320、build 22012444。先单独安装官方 UE4SS 实验版；已验证归档为 UE4SS_v3.0.1-1181-g83330635.zip。

  1. 下载并解压源码 ZIP，准备 Python 3、Clang、LLVM dlltool 与 lld-link，在源码目录构建： 
    python3 tools/package.py
    依赖与检查命令见构建说明。
  2. 退出游戏，解压生成的 dist/OT0AutoResolve-0.1.0.zip，将其中 OT0AutoResolve 文件夹复制到： 
    Octopath_Traveler0\Binaries\Win64\ue4ss\Mods\
  3. 保留 enabled.txt。若加载器使用 ue4ss/Mods/mods.txt，启用 OT0AutoResolve : 1，保留其他条目。
  4. 进入普通地图即可生效；按 F6 切换自动结算。

仓库 ZIP 是源码，不含预编译原生 DLL。请先构建安装包；保留现有加载器设置与其他 Mod。

设置

配置文件位于 ue4ss\Mods\OT0AutoResolve\config.ini。编辑后重启游戏。

[General]
Enabled=1
LevelMargin=1
ShowUI=1
Enabled
1 启用，0 关闭；快捷键会保存此值。
LevelMargin
等级差范围 0–99，默认 1；设为 0 可同等级结算。
ShowUI
1 显示奖励提示，0 隐藏。

升级与卸载

升级

退出游戏后，只替换 OT0AutoResolve\Scripts 文件夹（含原生 DLL），保留已有 config.ini 和其他 Mod。

卸载

退出游戏，删除 ue4ss\Mods\OT0AutoResolve 文件夹，并移除 ue4ss\Mods\mods.txt 中对应的一行。其他 Mod 仍需 UE4SS 时，请保留共享加载器文件。

常见问题

按 F6 没有反应怎么办？

检查 UE4SS 是否启动、enabled.txt 或现有 mods.txt 条目，以及 Scripts/ot0_native.dll 是否已构建并安装。F6 为固定快捷键；手动编辑配置后重启游戏。

为什么普通敌人仍进入战斗？

检查队伍等级是否达到当前门槛，并确认该战斗由地图移动触发。Boss、剧情、固定事件及无法确认的遭遇始终保留正常战斗。

奖励异常时去哪里查看记录？

Mod 不主动保存游戏。接口不可用时会保留正常战斗；奖励写入异常会停止后续自动结算，记录在游戏的 Win64/ue4ss/Mods/OT0AutoResolve/OT0AutoResolve.log 中。
