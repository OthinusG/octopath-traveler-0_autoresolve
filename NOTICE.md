# Notices

This is an unofficial community mod and is not affiliated with Square Enix.
It uses UE4SS as a separately installed loader; UE4SS is not included here.

The project was inspired by encounter auto-resolve mods for other games, but
uses OT0-specific native interfaces and build checks. No game assets, save data,
PDBs, SDK dumps, or UE4SS binaries are included.

No separate redistribution license has been granted for the OT0 mod source;
all rights are reserved. The original UE4SS MIT notice is preserved in
[LICENSES/UE4SS-MIT.txt](LICENSES/UE4SS-MIT.txt) and applies only to UE4SS.
